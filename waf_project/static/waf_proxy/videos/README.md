# Video Files

Place your video files in this directory.

## Supported Formats
- MP4 (recommended)
- WebM
- OGV

## Recommended Settings
- Resolution: 1920x1080 or lower
- Format: MP4 with H.264 codec
- Audio: AAC codec
- File size: Keep under 50MB for web performance

## Usage
The blocked.html template will automatically look for:
- `security-alert.mp4` (main video)
- `security-alert.webm` (fallback)
- `security-alert.ogv` (fallback)

## To Add Your Video
1. Copy your video file to this directory
2. Rename it to `security-alert.mp4`
3. Optionally create WebM and OGV versions for better browser compatibility
