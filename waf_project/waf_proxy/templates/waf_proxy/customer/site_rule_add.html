Pattern Examples
Common Attack Patterns:
Attack Type Pattern Example Description
SQL Injection (union|select|insert|update|delete|drop) Matches SQL keywords
XSS <script.*?>|javascript:|onload= Matches script tags and JS events
Path Traversal \.\./|\.\.\\\ Matches directory traversal patterns
Command Injection (;|&&|\|\|).*?(ls|cat|wget|curl) Matches command chaining
Bot Detection (bot|crawler|spider|scraper) Matches common bot user agents
Regex Tips:
  • .* - Matches any character sequence
  • ^ - Start of string
  • $ - End of string
  • \s+ - One or more whitespace characters
  • (option1|option2) - Either option1 or option2
  • [a-z] - Any lowercase letter
  • \d+ - One or more digits
