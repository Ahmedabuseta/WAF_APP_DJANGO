🔰 Overview

The WAF Security API provides programmatic access to manage your web application firewall settings, view security logs, and configure protection rules.

Base URL: https://api.wafsecurity.com/v1
Current Version: v1.0
Format: JSON

🔐 Authentication

All API requests require authentication using an API key. Include your API key in the request headers:

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Security Note: Keep your API keys secure and never expose them in client-side code.

📡 API Endpoints

Sites Management

Method Endpoint Description
GET /sites List all sites
POST /sites Create a new site
GET /sites/{id} Get site details
PUT /sites/{id} Update site configuration
DELETE /sites/{id} Delete a site

Security Rules

Method Endpoint Description
GET /rules List security rules
POST /rules Create a new rule
GET /sites/{site_id}/rules Get rules for a site
POST /sites/{site_id}/rules Add rule to site

Security Logs

Method Endpoint Description
GET /logs Get security logs
GET /sites/{site_id}/logs Get logs for specific site
GET /stats Get security statistics

🔗 Webhooks

Configure webhooks to receive real-time notifications about security events:

Available Events:

  • security.threat_detected - When a threat is blocked
  • security.site_added - When a new site is protected
  • security.rule_triggered - When a security rule is triggered
  • security.anomaly_detected - When unusual patterns are detected

Webhook Payload Example:

{
  "event": "security.threat_detected",
  "timestamp": "2024-01-15T10:30:00Z",
  "site_id": 123,
  "data": {
    "threat_type": "SQL_INJECTION",
    "client_ip": "192.168.1.100",
    "blocked": true,
    "rule_name": "SQL Injection Protection"
  }
}

💡 Code Examples

Create a New Site

curl -X POST https://api.wafsecurity.com/v1/sites \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Website",
    "domain": "example.com",
    "backend_url": "https://my-server.com"
  }'

Add Security Rule

curl -X POST https://api.wafsecurity.com/v1/rules \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Block SQL Injection",
    "pattern": "(union|select|drop|insert)",
    "rule_type": "SQL_INJECTION",
    "action": "BLOCK"
  }'

Get Security Logs

curl -X GET "https://api.wafsecurity.com/v1/logs?limit=50&status=BLOCKED" \
  -H "Authorization: Bearer YOUR_API_KEY"
